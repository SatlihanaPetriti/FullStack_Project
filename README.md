# Ecomus Plantshop

**Ecomus Plantshop** is a full-stack e-commerce web application designed for browsing and purchasing plants online.

The website provides a complete shopping experience for customers, including product browsing, favorites, shopping cart, online payments, orders, newsletters, and user accounts. It also includes an admin dashboard for managing the store.

## Website

**https://myplantshop.netlify.app/**

---

## Features

###  User Authentication

Users can create and manage their accounts through the authentication system.

* User registration
* Login and logout
* Secure JWT authentication
* Password reset
* User session management
* Personal user dashboard

---

### Products

Users can explore the available plants and view detailed information about each product.

* Browse plants
* View product details
* Product images
* Product variants
* Product prices
* Stock availability
* Browse products by category
* Product pagination

---

### Plant Categories

Plants are organized into different categories to make browsing easier.

Users can explore categories such as indoor, outdoor, pet-friendly, and other plant collections.

Each category contains its related products and has its own image and information.

---

### Favorites

Logged-in users can save products they are interested in.

Users can:

* Add products to favorites
* Remove products from favorites
* View saved products
* Manage favorites from their dashboard

---

### Shopping Cart

The shopping cart allows users to prepare their order before checkout.

Users can:

* Add products to the cart
* Select product variants
* Change product quantities
* Remove products
* Clear the shopping cart
* Review products before checkout

---

### Checkout & Online Payments

The website includes an online checkout and payment system powered by **Stripe**.

Users can:

* Review their order
* Enter checkout information
* Pay securely online
* Confirm successful payments
* Create an order after checkout

---

### Orders

After completing a purchase, users can access their orders from their account.

Users can:

* View previous orders
* View order details
* Track the current order status

---

### Newsletter

Ecomus Plantshop includes a newsletter system that allows visitors and customers to stay updated.

Users can:

* Subscribe using their email address
* Receive newsletters
* Stay informed about products and store updates
* Unsubscribe from the newsletter

---

### Contact

The website includes a contact functionality where visitors can send messages and inquiries.

This allows customers to communicate directly with the store when they need additional information or assistance.

---

## User Dashboard

Registered users have access to a personal dashboard where they can manage their activity on the website.

The dashboard includes:

* Account information
* Favorite products
* Shopping activity
* Previous orders
* Order details

---

## Admin Dashboard

The website includes a dedicated admin dashboard for store management.

Administrators can manage the main content and operations of the online shop.

### Product Management

Admins can:

* Create new products
* Edit products
* Delete products
* Upload product images
* Manage product variants
* Update prices
* Add and manage stock

### Category Management

Admins can:

* Create new categories
* Upload category images
* Edit categories
* Delete categories
* Manage products associated with categories

### Order Management

Admins can:

* View customer orders
* View individual order details
* Update order status
* Manage the order process

### Newsletter Management

Admins can:

* View newsletter subscribers
* Manage subscribers
* Send newsletters and store updates

* Favorites
* Shopping cart
* Orders
* Product management
* Category management
* Administrative operations
